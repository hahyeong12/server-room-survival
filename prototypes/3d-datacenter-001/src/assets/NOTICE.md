# Map data

`land.geojson`: Natural Earth 1:110m physical land polygons.
Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
Terms: https://www.naturalearthdata.com/about/terms-of-use/ — Public Domain.
Retrieved 2026-11-20. The application projects this land outline itself; it contains no country boundaries or real submarine cable data.

Photographs used for design reference are linked in `docs/3d-world-expansion/REFERENCES.md`. They are not bundled as application assets.
