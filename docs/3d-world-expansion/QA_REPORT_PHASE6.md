## 3. 독립 코드 리뷰와 수정

별도 리뷰 에이전트가 c6c0140 이후 전체 변경을 읽기 전용으로 검토했습니다. 지적과 처리:

| 지적 | 처리 |
| --- | --- |
| 결과 화면을 다른 방법으로 닫으면 다음 교대/재도전 버튼이 사라짐 (High) | 결과 탭에 [교대 N 시작]/[재도전]/[결과 다시 보기]를 항상 표시. QA 5번이 이 경로를 실제로 사용 |
| 어댑터가 파일 읽기 실패 시 자유 운영 저장을 교대 저장으로 볼 수 있음 → 잠금 우회 | 종류를 연 세션에서 결정, 교대 재도전은 교대 저장만. 회귀 테스트 추가 |
| 압축 배치 CSS가 기존 모드의 안내 문구를 숨김 | 모든 규칙을 글로벌 모드(`body[data-mode=global]`)로 한정 — 기존 모드 배치 불변 |
| 개발용 seed 결과를 증거로 쓸 위험 | 최종 증거는 seed 없는 실행만(`phase6-qa.json`), 개발용 파일은 커밋하지 않음 |
| `mark_shift_seen` 임의 키 허용 | 끝난 현재 교대 키만 허용 |
| 교대 첫 도착이 0분이 아니면 세션 생성 실패 | 카탈로그 검증에 추가 |
| "3개 모두 클리어" 문구가 재도전 슬롯에서도 표시 | 기록으로 모든 교대 클리어가 확인될 때만 |
| 기존 모드에서 새 도시 클릭이 오클릭으로 집계 | 기존 모드에서는 무시 |
| Vite가 `aidc/global_ops/` 전체를 허용 | 카탈로그 JSON 파일 하나만 허용 |

남긴 것(문서화): 교대 브리핑 전에도 배정·대기·거절은 가능(시간은 멈춰 있어 결과에 영향 없음).
