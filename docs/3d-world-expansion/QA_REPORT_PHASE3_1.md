## 미검증·한계

- **사람의 주관 평가**(10초 이해, 관제실 분위기, 눈의 피로도)는 자동화할 수 없어 Phase 3 사용자 플레이 평가로 남깁니다.
- 물리 마우스, Windows 배율 125/150%, 다른 GPU/저사양 환경은 미검증입니다.
- 냉각은 교육용 보조 계통의 고정 수치이며 물리 열모델·Python 게임 판정이 없습니다. 실제 운영 절차를 뜻하지 않습니다(화면에 명시).
- 관제동과 서버동은 원래 한 장면의 두 구역을 클리핑으로 분리한 것입니다. 별도 실내 모델링이나 캐릭터 이동은 구현하지 않았습니다(Issue 범위상 불필요).
- 산단·캠퍼스는 자체 저폴리 재구성이며 실제 부지 경계·조감도가 아닙니다. 세계지도 정밀도(1:110m)로는 황성동과 동구를 구분할 수 없어 좌표만 남구 권역으로 지정했습니다.
