# Phase 9 참고 근거

2026-11-27 공식 원문 확인.

- [AWS Well-Architected REL12](https://docs.aws.amazon.com/wellarchitected/latest/framework/rel12.html): 통제된 실패 주입, 종료 조건, 복구 경로와 관측의 반복 검증.
- [Google SRE Incident Response](https://sre.google/workbook/incident-response/): 역할 분리, 담당팀 조정, 고객 소통, 대응 기록.
- [Google SRE Postmortem Culture](https://sre.google/sre-book/postmortem-culture/): 사건 영향·조치·후속 개선을 남기는 비난 없는 회고.

위 자료는 실제 운영의 조사·소통·학습 원칙을 참고하는 근거입니다. 게임의 가상 시간, 장애 확률, 점수, 직급은 교육 설계이며 실제 조직 표준을 재현한다고 주장하지 않습니다. Linux 문법은 Phase8 공식 참고 문서를 이어 사용하고 새 실제 OS 호출은 추가하지 않습니다.
