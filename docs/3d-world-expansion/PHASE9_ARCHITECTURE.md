```text
GlobalSession → IncidentSession → LinuxSession
                                   ├ SeniorSession + OperatingRules

          ↓ 기존 요청·계약·동의·서버 원장·가상 시계·기한·반환
```

`OperatingRules`는 Phase9 전용 규칙 덧층입니다(자유 교대·선임 평가에만 섞임). OOM 메모리 설정/스토리지 확장의 플랫폼 호출을 실제 승인 요청으로 표시합니다. 기존 v1 정의의 "이상 없음" 공통 응답과 혼동되던 경로를 새 세션에서만 개선하며, 기존 사건/글로벌/Linux 저장은 자동 변경하지 않습니다.

- 감속은 `_job_hold`/`_hold_tick` 덧층으로 실제 진행률·완료 시각에 반영되고 원장 `slow_minutes`에 기록됩니다. 적용 대상은 요청 번호가 아니라 **그 우회를 실제로 지나는 작업**(hold 유형은 서버 원장으로 `rec.servers` 위 작업, 그 외는 실행 중인 해당 작업)입니다. 처리 구간은 화면에 표시한 분과 같고(끝 시각 포함), 정지와 겹친 구간은 감속 분으로 중복 기록하지 않습니다.
- 측정(10분 시계, `tests/test_operating_branches.py`): 남은 정상 속도 작업 20분 → 7유형 모두 임시 우회가 먼저 완료, 100분 → 근본 조치가 먼저 완료(정지형은 약 50분부터). 감속형(혼잡·I/O)은 20~40분 구간에서 완료 시각이 같을 수 있습니다.
- 버튼 비용 문구는 플레이어가 원인을 판단한 사건에만 그 유형의 우회만 표시합니다(판단 전에는 빈 값). 판독에도 "원인은 해소됨 · 임시 우회 운전 중" 줄을 덧붙여 화면·판독·엔진 상태가 일치합니다.
- 배치 축소는 동의 뒤 시간이 지나 기한을 넘기게 되면 **조건 거부**(`condition: true`)합니다. 안전 위반으로 세지 않으며 다른 합법 경로(메모리 절약 설정)를 쓸 수 있습니다.
- (3차 재리뷰 수정, 규칙 `;deadline-ceil10`) 동의 판정과 배치 축소 재확인은 남은 작업 시간을 **10분 단위로 올림**(`ceil10`)합니다. 이전 식 `int(x + 9) // 10 * 10`은 60.5분을 60분으로 내려 동의한 배치 축소가 10분 늦게 끝날 수 있었습니다. Phase 7 사건/Linux 저장의 동의 판정은 같은 식을 `IncidentSession._consent_finish()` 훅으로 옮겨 **그대로 유지**하고, 덧층만 올림 식으로 재정의합니다(기존 근무 판정 불변, 알려진 한계로 기록).
- 규칙 지문이 바뀌었으므로 이전 Phase9 규칙으로 만든 자유/선임 저장은 "이전 버전의 Phase 9 운영·평가 규칙"(자유) / "이전 버전의 Phase 9 평가·운영 규칙"(선임) 안내와 함께 열지 않습니다(원본 보존, 소급 재해석 금지). 미공개 실험 브랜치의 QA 임시 저장만 해당합니다.

## 자유 교대 사건

새 `global_free`는 `FreeShiftSession`입니다. 저장 파일 이름은 같은 독점 생성 `aidc_3d_global_NNN.db`, 모드는 `global`, 종류는 `free`이며, 새 `free_incidents` JSON v1으로 구분합니다. 기존 free 저장에 이 블록이 없으면 기존 `GlobalSession`으로 엽니다. 반대로 새 형식을 기존 `GlobalSession`으로 열면 쓰기 전에 거부합니다.

| 난도 | 첫 검사 간격 | 이후 간격 | 동시 활성 상한 |
| --- | --- | --- | --- |
| 무사건 | 없음 | 없음 | 0 |
| 편안한 | 80분 | 80/90/100분 | 1 |
| 표준 | 40분 | 40/50/60분 | 2 |
| 도전 | 20분 | 20/30/40분 | 2 |

모든 시각은 가상 10분 경계입니다. `random.Random(f'{seed}:free-incidents-v1:{cursor}')`로 각 검사 시각을 독립 재현합니다. 검사 순번은 대상 없음/동시 상한으로 건너뛴 경우에도 소비하고, 같은 시각의 재호출은 소비하지 않습니다. 화면 이동·다시 그리기·실시간 대기는 소비하지 않습니다.

적격 대상은 실제 실행 중·배정 유지·장비 중단/이전 준비 없음·다른 사건 영향 없음·이 요청의 이전 사건 없음·남은 정상 작업 20분 이상·정상 완료 예상보다 기한 여유 60분 이상인 요청입니다. 그중 대상과 10유형을 추첨합니다. 냉각/UPS의 공유 영향 범위, 작업 보류/둔화, 신규 배정 차단, GPU 격리/이전/수리는 기존 엔진을 그대로 씁니다. 안전 대응은 각 유형의 기존 시설팀 요청·계획 중단 등으로 가능합니다. 적격성은 실제 결과의 성공을 보장하지 않으며 플레이어의 후속 선택에 따라 실패할 수 있습니다.

저장 블록은 규칙 지문·난도·cursor·last·next·발생 이력·closing을 보존합니다. 이력은 사건 ID/요청 ID/유형/발생 가상 시각/검사 순번과 연결 검증합니다. 사건 정의 지문은 부모가 검사합니다. 난도/적격성/승인 규칙이 바뀌면 같은 저장을 조용히 재해석하지 않습니다. 모든 필드는 기존 게임/사건/Linux와 같은 `_atomic()` 단위로 롤백됩니다.

브리핑 전에 업무 변이를 차단합니다. 초기 요청은 시작 화면의 고정 접수 상태이고, 시간/새 접수/사건은 근무 시작 후에만 진행됩니다. [교대 마무리·결과 보기]는 새 요청과 새 사건을 멈춥니다. 이미 열린 고객 요청·사건을 처리/안전한 종료 보고하고 모두 끝내면 결과를 한 번 고정합니다. 마친 교대는 시간/배정/사건 대응을 재개하지 않으며 결과 열람만 가능합니다. 새 자유 교대는 새 seed, 재도전은 같은 seed·난도로 새 슬롯입니다. 자유 결과는 진급 증거로 사용하지 않습니다.

가상 터미널은 선택 사항입니다. 시각 관측과 CLI 모두 동일 `IncidentRecord`, 서버 위치, `reading()`을 조회합니다. CLI 범위 비교·토큰·출력 비공개 필드·입력 길이/구문 제약·실제 셸 차단은 Phase8 구현을 재사용합니다. 자유 모드는 시각 관측만으로도 진단·검증할 수 있고, 정규 Linux/선임 평가는 기존의 필수 보완 CLI 근거를 요구합니다.

평가 v3(3차 재리뷰 반영, 아래 v2 설명에 두 가지를 더함): ① 계획 없이 거절된 조치는 정책 목록(데이터 삭제·UPS 우회·무동의 배치 축소)만 안전 감점이며, 조건 변경이 필요 없는 사건에서 고객 동의를 요청한 것은 감점하지 않습니다. ② 선택 CLI 자유 교대에서 한 사건에 두 출처(터미널 해석·결정적 가설)를 모두 썼다면 **각 출처의 첫 답이 모두 맞아야** 정답입니다. 한쪽의 틀린 첫 답을 다른 쪽의 나중 정답으로 바꿀 수 없습니다. 자유 저장 지문에도 평가 지문을 포함해 평가 규칙이 바뀌면 이전 자유 저장을 열지 않습니다.

평가 v2(Claude Code 수정, 독립 리뷰 반영). 평가 기회 자체가 없으면 그 항목은 제외해 환산합니다. 사건이 있는데 해석하지 않은 것은 기회 없음이 아니며 0점입니다. 같은 사건에서 재조회/반복 정답으로 점수를 늘리지 못합니다. 정규 Linux/선임은 모든 사건을 CLI 해석으로 평가합니다. 선택 CLI인 자유 교대는 **사건별로** 판단합니다: 그 사건에 터미널을 썼다면 터미널 해석(미응답 0), 쓰지 않았다면 그 사건의 첫 결정적 가설(근거 있는 판단)입니다(v1은 한 번만 터미널을 써도 모든 사건이 터미널 기준이 되어 GUI 진단 사건이 0점이 되는 결함). 안전은 정책 거부(데이터 삭제·UPS 우회·무동의 조건 변경)와 승인/동의 전 시도만 감점하고, 엔진의 조건 확인 거부(우회 경로 없음·이전 용량 부족·기한상 배치 축소 불가)는 감점하지 않습니다. 실시간 생각/설명 읽기/화면 재방문/장애 자체는 감점하지 않습니다. 운영 영향의 정지·지연·기한·자원 위치는 기존 사건/요청 결과표에 그대로 나타납니다.

3D `GameHost.career()`는 현재 3D 저장 폴더의 정규 결과만 읽어 경력 지도를 계산합니다. 연습/자유/튜토리얼은 제외합니다. 권장 순서는 제1~5장 → 글로벌3 → 사건3 → Linux5 → 선임2입니다. 이전 제5장 수료자의 Linux 입장 조건은 보존하고, 최종 평가만 전체 수료를 요구합니다. 직무(신입/담당/선임)와 교육 수료(운영/독립 관제 엔지니어)는 별도 필드입니다.

## UI와 검증 실행

메뉴의 경력 지도, 내 모니터의 별도 두 평가, 오른쪽 현재 목표의 교대 종료 버튼, 사건 상태별 복구/검증/보고 피드백을 추가했습니다. 세계/랙/시설 상태는 기존 렌더러에 같은 엔진 사건을 공급합니다. 터미널 확대·Esc·사건별 출력/초안/히스토리·움직임 줄이기를 유지합니다.

`scripts/phase9-qa.mjs`는 임시 DB/별도8789·5189 포트에서 메뉴·마우스·키보드·선택·타이핑만으로 진행합니다. `phase9-regression.mjs --tag=이름`은 Phase8→7→6→5→4→lab→Python→adapter→JS→build를 별도 Phase9 증거 폴더에 기록합니다. 사용자 저장이나 과거 QA를 열어 진행하지 않습니다. 기존 Phase6 자유 운영 검사의 준비 단계만 무사건 선택+브리핑 확인으로 바꾸었고 기대 판정은 유지했습니다.
