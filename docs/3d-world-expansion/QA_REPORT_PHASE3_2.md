## 기능별 자동 검증

- **한국 중심 지도:** 울산이 캔버스 가로 중앙 ±10% 안. 배경 회선 14개, 불투명도 0.55의 어두운 정적 선. 새 요청 때 요청 경로만 금색 점등과 패킷 이동. 장애 때는 해저 구간 청록 유지, AIDC 마지막 구간만 빨강과 경고 배지, 경로 상세의 AIDC 칸만 `bad`. [움직임 줄이기]를 켜면 패킷 정지. 캡처: `world-request-incoming.png`, `world-fault-aidc-hop.png`.
- **랙:** 천장 설비 기본 컷(벽 + 천장 평면), 요청 랙 윤곽은 항상 위에 그려지고 핀 표시. 두 카메라 시점(서버동 전체/랙 보기)에서 D-06 실제 캔버스 클릭 적중. 천장 조명 위치를 클릭해도 랙만 선택됨(조명은 선택 대상 아님, 결과 `D-02`). 목록(키보드)과 [랙 D-06 찾기] 버튼 대안. 캡처: `rack-before-ceiling-shown.png`(천장 보임) / `rack-after-ceiling-cut.png`(천장 컷), `rack-hit-*.png`.
- **건물 6동:** 한 번 클릭은 선택·정보 패널만 열고 카메라는 그대로 둠(카메라 상태 동일 확인). 두 번 클릭은 관제동 → 내 자리, 서버동 → 랙, 냉각·전력·UPS·네트워크 → 각 기능성 내부로 진입. 내부 조작이 3D에 반영됨(보조 냉각 끄면 펌프 정지·흐름 소멸, 전력 점검·UPS 자가진단 완료 표시, 네트워크 원인 조회 시 표시 갱신). Enter 키 대안, [상위 공간]으로 캠퍼스 복귀. 요청 도메인 불변.
- **멈춤 회귀:** 관제동 → 서버동 이동 클릭이 20 ms에 반환되고 400 ms 안에 이동 안내 표시. QA 중 발견한 1.5 s 셰이더 재컴파일 멈춤의 수정 확인.

## 발견·수정한 문제 (QA 중)

1. 건물 이동 시 약 1.5 s 멈춤(전역 클리핑 평면 개수 변화로 셰이더 전체 재컴파일) → 평면 슬롯 2개 고정 + 로딩 중 사전 컴파일.
2. 모든 랙의 클릭 영역을 키우자 뒷줄 랙을 눌러도 앞줄 랙이 선택됨 → 정확한 랙 형상 판정 유지, 목표 랙만 클릭 영역 확대.
3. 짧은 화면(1366×768, 150%)에서 장면 제목·공간 탭·내 모니터가 겹침 → 배치 조정, 겹침 자동 검사 추가.
4. QA 1회 실행 중 Chrome "Target crashed" 1건 → 오프닝 3회 반복 메모리 관찰(힙 25–37 MiB 일정, 지오메트리 고정)과 이후 모든 실행에서 재현되지 않음. 원인 미확정으로 기록.
