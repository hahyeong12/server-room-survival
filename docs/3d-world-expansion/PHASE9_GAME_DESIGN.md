# Phase 9 게임 설계 (구현 전 기준)

작성: 2026-11-27. Issue #10 전체를 확인했습니다. 기준은 Phase8 `3893cb6`, 브랜치는 `experiment/3d-growth-balance-phase9`입니다. 이 문서의 설계는 구현 완료 주장이 아닙니다.

## 성장과 유한 결말

기존 제1~5장 → 글로벌 3교대 → 사건 3교대 → Linux 5근무 → 신규 선임 평가 2교대 → 동료 축하·엔딩·크레딧 → 선택적 자유 운영으로 연결합니다. 기존 Linux 입장 조건(제5장 수료)은 호환성을 위해 유지하며, 경력 지도에서 권장 순서를 보여 줍니다. 최종 평가는 모든 정규 과정의 완료 근거를 요구합니다. 교육 수료 명칭은 보존하고 직무(신입/담당/선임)를 별도 표시합니다.

최종 평가는 LinuxSession의 증거·해석·승인·복구 후 확인을 그대로 사용하면서 새 요청 조합과 중첩 사건, 자원 충돌을 평가합니다. 실패하면 새 슬롯에서 같은 평가를 재도전합니다. 점수는 저장된 원장을 읽어 계산하며 클릭 보상이나 누적 경험치가 아닙니다. 재실행·재시작으로 중복 보상을 받지 않습니다.

## P0 자유 교대

새 글로벌 자유 교대에만 IncidentSession의 상태 기계와 실제 작업 영향·범위·승인·원장을 결합합니다. 기존 글로벌 v1 저장은 원래 규칙으로 엽니다. 새 버전 블록은 seed·난도·마지막 검사 시각·추첨 순번·생성 이력을 보존합니다. 일정/검사 시각은 가상 10분 경계이며 화면 이동·실시간 대기는 난수나 시계를 소비하지 않습니다.

난도는 무사건/편안한/표준/도전입니다. 무사건은 0건, 편안한은 동시 1건과 긴 간격, 표준·도전은 최대 2건으로 제한합니다. 실제 실행 중인 요청, 서버 배정, 남은 작업과 계약 여유를 검사합니다. 이미 사건을 가진 요청에는 재주입하지 않습니다. 사건은 기존 10종에서 추첨하며 교육용 가상값임을 표시합니다. 생성 가능성이 없으면 그 시각은 건너뛰고 재추첨을 반복하지 않습니다.

브리핑 전 모든 업무 변경을 잠급니다. [교대 마무리·결과 보기]는 신규 접수를 멈추고 남은 요청·사건을 처리하도록 안내합니다. 모두 종료하면 고정된 결과를 저장하고 새 교대/이어하기를 구분합니다. 자유 교대는 정규 진급에 사용하지 않습니다.

## 선택과 비용

기존 사건 v1 정의를 소급 변경하지 않습니다. DNS(보조 전환/담당 복구), ToR(이중화/담당 복구), GPU 건강(이전/수리), OOM(동의 후 축소/담당 설정), 공간(임시 정리/승인 확장), CrashLoop(롤백/설정 재배포) 등 최소 6유형의 서로 다른 복구 시간·승인·서버 위치·고객 동의 결과를 검증합니다. 자원이 없거나 계약·안전 규칙을 위반하면 이유와 함께 거부합니다. 냉각·UPS는 시설팀 분업을 유지합니다.

## 공정한 두 평가

운영은 기존 요청 결과(기한 준수·허용 조건), 사건 해결·검증·고객 안내 및 안전한 조치를 평가합니다. 학습은 실제 관측·해석·가설·힌트 기록을 평가합니다. 구체적 가중치는 실제 원장 필드 확인 후 별도 평가 모듈과 문서에 함께 고정합니다. 실시간 생각하는 시간, 설명 읽기 속도, 화면 재방문, 사건 발생 자체를 감점하지 않습니다. 통제 불가능한 장애 빈도에 따라 점수가 달라지지 않도록 각 항목은 해당 기회의 비율로 계산합니다.

## 안내와 화면

현재 역할·오늘 목표·다음 행동·종료 조건을 한 화면에서 보여 줍니다. 초반 선배 단계 안내 → 중반 요청형 안내 → 선임 최소 안내입니다. 오답 직후 정답 공개 없이 추가 근거를 안내합니다. 터미널 확대·Esc·입력/히스토리와 사건 범위 비교를 보존합니다. 실제 Python 사건 결과를 기존 랙·세계 경로·시설 상태로 전달합니다. reduced motion에서도 문구·아이콘으로 결과를 이해할 수 있어야 합니다.

## 검증 계약

OS 임시 DB만 사용합니다. 보호 대상은 이전 1,047개를 포함해 새 기준선을 기록합니다. P0 재현성·10종 도달·중첩·저장/재시작·가상 시간 경계, 분기 A/B·반례, 두 점수·중복 방지, 최종 2교대 실제 브라우저 완주, Phase4~8/lab 회귀, Python/adapter/JS/build를 검증합니다. 사람의 재미·긴장·학습 효과는 자동 QA로 검증됐다고 주장하지 않습니다. 독립 리뷰 후 발견 결함을 수정하고 최종 재실행합니다.
