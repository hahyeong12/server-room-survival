## 6. 한계와 미구현(정직한 표기)

- Tk GUI 311개는 지침에 따라 실행하지 않았습니다. 원본 Python 변경(`session.py` 훅, `GlobalSession` 잠금)은 비GUI 839개로만 검증했습니다.
- 사건 수치·배치·로그는 모두 교육용 가상 모델입니다. 실제 장비 열/유체/전기 동작, VRAM 수치, 특정 UPS 제품의 경보 순서는 모델링하지 않았습니다.
- 글로벌 자유 운영의 seed 기반 무작위 사건은 이번 범위에서 구현하지 않았습니다(사건은 근무 A~C와 개별 연습의 결정적 일정으로만 발생). Issue의 "자유 운영에는 설정된 난도/선택적 seed 난수" 항목은 **미구현**입니다.
- 명령어는 '예시'로만 표시되며 입력 가능한 가상 명령은 없습니다(Phase 8 범위).
- 브라우저 QA의 해상도는 Chrome 기기 배율 에뮬레이션입니다(실제 Windows 150% 배율 변경은 하지 않음).
- 엔진 수정 전 첫 보고 실행에서 포트 검사가 거짓 통과였던 사실은 4절에 그대로 남겼습니다.
