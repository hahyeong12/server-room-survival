## 외부 창 중단 원인 분석

### 확인한 사실

- 게임 루트 위의 외부 최상위 창을 Win32 Z 순서로 조사했습니다. 두 번 모두 같은 큰 사각형이 게임 영역과 겹쳤고, 5초 대기 동안 사각형이 바뀌지 않았습니다.
- 화면 물리 좌표에서 외부 창 사각형은 `(-14, 0, 1415, 1020)`, 게임과의 교차는 `(335, 118, 1415, 930)`입니다. 교차 면적은 **876,960픽셀**입니다. 이는 어떤 앱인지 추정하기 위한 제목이나 화면 내용이 아니라 기하 정보입니다.
- 2회차에는 자체 게임 창 최초 활성화 전후 모두 전경 창이 아니었다는 부울 값이 기록됐습니다. 실제 클릭 직전 가림이 해소되지 않았고, 입력 함수를 호출하지 않았습니다.
- 외부 영역이 포함될 수 있는 이미지는 저장하지 않았습니다. 가림 중단 장면 캡처도 없습니다.

### 해석과 한계

두 번의 큰 동일 영역과 전경 상태를 보면 **게임 창이 다른 창 뒤에 남아 시작된 상황에 부합합니다(추론)**. 잠깐 나타났다가 사라지는 작은 알림은 관찰되지 않았습니다. 자체 창 활성화 시도가 전경 상태를 바꾸지 못한 정확한 OS 원인, 어떤 외부 앱이었는지, 사용자가 창을 조작했는지는 확인하지 않았습니다. 사용자 조작을 원인으로 단정할 수 없습니다.

story-001에는 외부 창의 기하·지속 시간·전경 상태가 없어 당시 원인을 소급 확정할 수 없습니다. 이번과 같은 원인이었다고도 단정하지 않습니다.

이번 감지는 게임 규칙 실패나 요청서 파서 오탐이 아닙니다. 외부 창과 게임 루트의 겹침을 보수적으로 검사하므로, 모든 교차 픽셀이 실제로 사용자에게 보였다고 보장하는 측정은 아닙니다. 다만 이번 2회차에는 게임이 전경 창도 아니었으므로 안전 검사를 무시할 근거가 없었습니다.

## 버그·오탐 및 UI/게임성 평가

- **S2-ENV-01 / 높음 / 실행 차단:** 시작 시 게임이 외부 창에 가려져 5초 뒤 중단. 재현 경로는 현재 실행 환경에서 QA 시작→첫 스토리 버튼 클릭 준비입니다. 위 기하·시간·전경 기록이 근거입니다. 원인은 외부 창이 앞에 남은 상황으로 추정하며 정확한 OS 이유는 미확정입니다.
- **S2-QA-01 / 미해결 제한:** 자체 창 최초 활성화가 전경 상태를 바꾸지 못했습니다. 안전 검사를 통과하지 못한 상황을 조작으로 우회하지 않았습니다. 다음 실행이 승인된다면 실제 데스크톱 접근·최초 전경 상태를 먼저 확인해야 합니다. 이번에는 세 번째 실행을 하지 않습니다.
- **게임 버그·UI 결함:** 새로 판정할 실제 플레이 증거가 없습니다. story-001의 메뉴 소개 문장 잘림·좁은 요청 목록·스크롤 후보는 이 보고서에서 재현했다고 주장하지 않습니다.
- **QA 오탐:** 이번에 요청서/스크롤 검사가 실행되지 않아 수정으로 오탐이 해소됐다고 보고할 수 없습니다. 가림이 생겼다가 사라지는 경우의 재개 역시 GUI 검증이 남습니다.

**AI의 주관적 UX·교육 경험 평가:** 이번에는 고객 업무를 전혀 플레이하지 못해 반복성·성장 체감·안내 중복·고객 전환 연출·클리어 몰입감·제2장 기대감을 새로 평가하지 않습니다. 기존 [story-001 관찰](../story-001/report.md)의 ‘동일한 조작 반복, 약한 고객 전환 연출’은 이전의 부분 플레이 의견이며 이번 재검증의 결론이 아닙니다. 완주 자료 없이 긍정·부정 평가를 덧붙이지 않았습니다.
