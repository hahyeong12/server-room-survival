## 범위·관측 한계·반영

- 원본 DB·슬롯·체크포인트·잠금 파일을 열어 플레이하거나 수정하지 않았습니다. 공개 JSON에는 원본 경로·개별 해시를 싣지 않았고, DB/잠금/임시 슬롯·민감 환경 정보는 커밋하지 않았습니다.
- 이번 완주에서 게임 엔진 직접 호출·상태 수정·Tk의 invoke/event_generate/yview/see를 통한 QA 진행은 하지 않았습니다. 게임 내부의 표시용 `see()`는 이번 UI 수정이며, QA는 실제 클릭·휠과 읽기 전용 조회만 사용합니다. 별도 컴포넌트 회귀 테스트의 세션 준비·Tk 스크롤 호출은 실제 플레이 실적과 구분합니다.
- 미검증: 다른 DPI/모니터, Preflight 실제 실패·외부 가림 해소/지속 경로, 게임의 실제 이어하기/재도전·절약형·협의·거절·기한 초과·저장 실패. 튜토리얼/자유 운영 전체 마우스 완주는 실행하지 않았습니다. 단일 정상 경로가 모든 회귀를 보장하지 않습니다.
- 기능별 커밋: `73f5d19` 요청함, `fd02886` 소개 줄바꿈, `014c23a` QA 검사 보완. 이후 이 보고서·실제 JSON/PNG를 별도 커밋합니다. 최종 Fetch·일반 Push 및 로컬/원격 HEAD 확인 결과는 작업 종료 응답에 기록합니다.
- 기존 story-001~003 기록은 그대로 보존합니다. 추가 게임 수정·다음 장 개발·제2장 자동 플레이는 진행하지 않았습니다.
